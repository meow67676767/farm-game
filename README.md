# Весёлая ферма (Kenney Tiny Farm)

2D-игра про ферму на Python с использованием библиотеки **Pygame Zero** (\pgzero\).
Спрайты из набора [Kenney Tiny Farm](https://kenney.nl/assets/tiny-farm).

![Скриншот игры](farm_game_screenshot.png)

## Возможности игры
- 🌾 Посадка и сбор урожая: морковь, томаты, кукуруза
- 💧 Полив грядок лейкой
- 🐮 Загон для животных (курицы, корова), сбор яиц и молока
- 💰 Экономика: продажа урожая, монеты и покупка семян
- 🎮 Удобное управление (WASD / стрелки, цифры 1-5, E / Пробел)

## Установка и запуск

1. Установите зависимости:
\\ash
pip install -r requirements.txt
\
2. Запустите игру:
\\ash
pgzrun farm_game.py
\или:
\\ash
python farm_game.py
\
